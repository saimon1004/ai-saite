# Chapter 1: ひらめきの瞬間
## アーク: 創業編（Founding）
## スキル: Terminal, HTML/CSS, Git, HTTP

## ストーリー概要
沖縄・那覇市のカフェで、主人公がフリーランスエンジニアのYukiと出会い、地元ビジネス向けプラットフォーム「ShimaLink」の開発を始める。最初の一歩として開発環境を構築する。

## 主要キャラクター
- あなた（主人公）: プログラミング初心者、ShimaLinkの創業者
- Yuki: フリーランスエンジニア、メンター役

## 学習内容
### ターミナル基礎
- 5つの基本コマンド: pwd, ls, cd, mkdir, touch
- 絶対パスと相対パスの違い
- ホームディレクトリ（~）の概念

### HTML/CSS
- HTMLの基本構造（DOCTYPE, html, head, body）
- 主要タグ（h1-h6, p, a, img, ul/li, div）
- インラインCSS（styleタグ）
- ShimaLinkのランディングページ作成

### Git
- バージョン管理の概念
- 3つのエリア: ワーキングディレクトリ → ステージング → リポジトリ
- 基本コマンド: init, status, add, commit, log, diff
- .gitignoreの重要性（セキュリティ）

### Web（HTTP/DNS）
- URLアクセス時の5ステップ（DNS→TCP/TLS→HTTP→レスポンス→描画）
- DNSの仕組み（ドメイン→IPアドレス変換）
- HTTP vs HTTPS（暗号化の重要性）
- ステータスコード（200, 301, 404, 500）
- クライアント/サーバーモデル
